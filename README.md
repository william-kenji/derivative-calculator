# derivative-calculator
In calculus, we are often concerned with the slope at a point in a graph. This code uses the power rule from Calculus to calculate the derivative of a function. Even if you are not a mathematician, you can still comment on the use of ***loops*** and ***if*** statements.

## How it works:
A user types in a function (e.g., **4x^6**)
The terminal prints out the derivative (**24x^5**)

> The idea is that the derivative of a function is: *(coefficient times the exponent) times x to a power one less than the original exponent*.
